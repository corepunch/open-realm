# Burrow invisibility and active-form ownership

Burrow366 implements the remaining Burrow producer behavior within SEP-01.2.
Forward completion and initial-alternate attachment acquire a counted Unit114
invisibility source. Reverse removes that source before the delayed type rebind.
The active form suspends other abilities through independent execution/order
contributions, retaining its own Morph and current Move/Attack exceptions.
Permanent Invisibility cancels its fade while suspended and restarts only after
reverse completion. Stop and scripted pause preserve the transition.

Four public maps have original, repeat and observer-free control captures:
12 captures, 15 scenes, 995 public markers and 1,943 native events. The frozen
contract reconstructs all four maps byte for byte and verifies 1,407 instruction
guards. Three Ghidra evidence scripts save the recovered functions and comments;
independent readbacks match. `MapPathfinding.java` records their 13 annotations.
Seventy-four evidence-integrity tests protect the captures and decoder.

Two initial-alternate aliases acquire separate invisibility and availability
owners. Removing the first restores the base type and releases its contribution.
Removing the second while already in the base type retains both contributions,
as retail does. A subsequently attached Permanent Invisibility ability inherits
the retained suspension. A normal forward/reverse cycle releases its own owners.
The sparse aggregate survives transition replacement and cold saves.

Early forward removal first completes the pending transition, then removes its
new subtype source and returns to base. Early reverse removal returns to base
without retaining the hold. Death cancels pending work and preserves the captured
raw type. Availability suspension callbacks run before hidden-state publication.
The implementation keeps detach traversal and callback reentrancy safe.

All behavior changes followed failing production regressions. The first hidden
owner regression failed 48 of 580 assertions per edition. Active-form availability
then exposed 40 missing assertions; two-alias ownership exposed six more, followed
by 18 retained passive-owner failures. The final callback-order and early-detach
regressions failed exactly 20 of 1,646 assertions per edition before their fixes.
The final private Save207 strict run passes 24 tests and 4,373 assertions in both
Classic and TFT, including cold-save and existing Morph/repulsion checks.

Unit118 is an embedded FloatProp bridge. Its vtable, reference count and registry
slot/generation stay literal. Only the proven modifier/listener heap pointers in
Unit128/12c use a consistent whole-capture bijection preserving null, aliasing
and reuse. Mutations of fresh registry generations or slots are rejected. A
separate diagnostic availability capture pair has different heap reuse topology
and remains rejected; it is not a frozen oracle input.

This closes the scoped Burrow behavior, while SEP-01.2 remains open for Mount
reachability, other common Morph producers and counted-owner composition/replay.
The common availability policy reads Misc/MorphAlternateDisable, default zero;
Burrow and Submerge override it with true. It is not an ability DataB flag.

The final isolated index snapshot compiles both production and test game modules.
Its strict gate passes24 tests/4,373 assertions per edition; the full save suite
passes223 tests/67,990 assertions per edition. All74 evidence-integrity checks,
38 corpus checks and12 exclusion-owner checks pass. Four component validators
are support modules of the single aggregate oracle, avoiding duplicate engine
runs. Reports are preserved under `SEP-01.2/burrow366/verified-private207-final2.json`.
