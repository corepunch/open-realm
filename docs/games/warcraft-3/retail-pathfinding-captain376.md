# Captain preferred targets and public SuicideUnit ownership

Captain376 implements the public Town preferred-target and `SuicideUnit` producers within the existing `GROUP-03.4.7.3` task. The final integration also replaces proven legacy classification readers with the live classification word. The clean Save 217 composition passes 53 focused tests / 3,330 assertions in both Classic and TFT. Historical private Save 216 results below remain immutable and are reported separately.

The Town's preferred identity is separate from the Captain's selected and followed identities. Melee policy can use that preferred identity as the effective primary. Actual structure-recipient help visits consume the Town latch before distance and rank checks. An independent two-second Town owner rearms the latch and performs defense-role maintenance. It does not borrow the Captain's periodic timer phase. Public Home changes, campaign/melee changes, owner withdrawal, closer replacement, rejected farther replacement, and warm/cold restoration exercise those owners.

Town and Captain subscriptions retain the native registration lifetime. Replacing a weak identity does not imply immediately unregistering every old listener. Typed owner records distinguish current roles from retained registration. Matching and unmatched callbacks remove the appropriate source registration; publisher destruction silently removes its remaining records before entity reuse, without issuing an extra TargetLost callback.

`SuicideUnit` selects actual owned units by class, quantity and eligible action. It withdraws selected Captain membership, records the requested target player on the AI-record incarnation, and admits the private `d000e` core order. The selector performs the recovered four query passes with the original bounded candidate list and random selection. It publishes an ordinary `d000f` point order toward the selected unit's world position, or an ordinary Stop when no candidate exists. An attached Attack owns the concrete point task; without Attack, Move owns the task while the logical issued ID remains `d000f`. An immobile disabled structure can admit the order without acquiring a physical movement group.

The target query uses the attached Attack's enabled-slot authored masks and native normalization. It does not substitute the general attack-execution predicate: that would introduce detection, Cyclone and execution restrictions absent from this selector. Public mutable types operate on the live classification word, including removal of authored mechanical, sapper and ancient properties. Hero classification for this query remains the rawcode first-character test recovered from retail. Same-type transformation is a true no-op, while actual reconstruction initializes the new type's classification. Save/load preserves the live word.

Issued-order callbacks may replace an order, remove its source, or retire its target. The implementation keeps the winning callback's order and checks entity incarnation before later alert work. A pending RemoveUnit immediately cancels public order and physical ownership; an engine-only waypoint cache is checked at its actual release frontier rather than assigned a guessed immediate retail field equivalent. Scripted Pause admission is tested after the established scheduled unpause owner boundary.

The Suicide flag belongs to the AI-record lifetime. A full Town-owned withdrawal clears it; role-matching early returns retain it. The regression obtains this state through the public producer, records the actual owner round trip and generation change, and only then checks help eligibility. It does not seed a private flag to manufacture an inverse test.
