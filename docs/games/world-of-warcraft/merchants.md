# Prototype merchants

Right-clicking a nearby, living imported NPC with the vendor flag opens a server-authored merchant panel. Quest-capable merchants expose a Quest button. The server rechecks the NPC, its vendor flag, and the ten-unit interaction radius for every transaction. Every five seconds, the game scans the imported vendor and banker spawn rows for the player's map and instantiates up to eight nearest NPCs within 2,000 units. It retires service-owned NPCs beyond 2,200 units, preserving quest NPCs and keeping eight edicts free for runtime entities. Existing quest NPCs at the same position are not duplicated. A spawn serial binds merchant and bank sessions to the specific NPC instance, so reuse of an edict cannot authorize an old session. The current extracted spawn CSV covers map 0 only.

The shared provisional stock is Minor Healing Potion (20 copper buy, 5 sell) and Tough Jerky (4 buy, 1 sell). These prices and the shared catalog are prototype values, not imported vendor inventories. Only these two known items can be sold; a sale transfers the entire stack. The most recent twelve stacks are retained for buyback at the sale price; the Buyback view shows all twelve. Buying and buyback require sufficient copper and inventory space. Buyback is currently session-only and does not persist across player resets.
